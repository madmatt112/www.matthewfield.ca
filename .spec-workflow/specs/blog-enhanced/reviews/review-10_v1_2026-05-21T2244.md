## Findings

### INFO [hygiene]: Unquoted directory interpolation in shell commands
- **File:** scripts/verify-pagefind-artifact.mjs:21
- **Issue:** Both `checksum()` and the diff command interpolate `${dir}`, `${sourceDir}`, and `${targetDir}` into bash strings without quoting. The values are hardcoded constants (`public/pagefind`, `.vercel/output/static/pagefind`) with no spaces or shell metacharacters, so this is safe in practice. Wrapping them in single quotes (e.g., `cd '${dir}'`) would be defensive in case the constants ever change. Not a correctness issue.

### INFO: spawnSync improvement over design's execSync for diff
- **File:** scripts/verify-pagefind-artifact.mjs:32
- **Issue:** Implementation uses `spawnSync` for the diff path instead of the design's `execSync` (which would throw on diff's non-zero exit when files differ — the expected case). This is a defensible deviation from the literal design code that actually makes the script work. Worth noting only because it's a divergence from the design snippet.
