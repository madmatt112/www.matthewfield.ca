### INFO: Assertion (2) reimplements getVisiblePublishedPosts predicate instead of calling it
- **File:** src/lib/visibility-truth-table.test.ts:172
- **Issue:** Layer 2 of the matrix filters a synthetic [post] via `list.filter((p) => !isHiddenFromLists(p))` rather than invoking getVisiblePublishedPosts() from @/lib/blog. The predicate is identical to the production helper (blog.ts:110), and the comment in the test (lines 173-176) acknowledges this is intentional to keep the assertion regime-discriminating against isHiddenFromLists. Functionally correct, but it means if the production helper's predicate ever diverges (e.g. also filters drafts or excludeFromSearch), the test would silently continue to pass. Could be tightened by mocking getPublishedPosts to return [post] (already done in vi.mock at line 130) and calling getVisiblePublishedPosts directly.

### INFO [hygiene]: extraSlugsFilter mirror is hand-copied — drift risk if buildExtraUrls changes
