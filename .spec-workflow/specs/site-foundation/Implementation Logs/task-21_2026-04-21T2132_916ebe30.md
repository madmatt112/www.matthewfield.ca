### Integrations

#### Integration
- **Description:** Next.js `headers()` config returns a single entry with source `/((?!playground(?:/|$)).*)` and a Content-Security-Policy header. The CSP directive string is defined in a module-level `cspDirectives` constant (next.config.ts:3-13) covering default-src, script-src, style-src, img-src, font-src, object-src, base-uri, frame-src, connect-src. Next.js path-to-regexp rejects capturing groups, so the inner alternation uses a non-capturing group `(?:/|$)` — this differs from the design doc's `(/|$)` example. The negative lookahead with segment boundary prevents /playground-tips (or any playground-prefixed route) from being accidentally excluded. Verified via `pnpm build` (production build compiles cleanly after the non-capturing-group fix). Runtime header verification is deferred to task 28 (e2e/tests/csp.test.ts) because this workspace's port 3000 is occupied by another project's dev server.
