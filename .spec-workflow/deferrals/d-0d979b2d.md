## Context
Task 15 review v1 flagged this as a WARNING. These are shadcn's published neutral-base defaults imported verbatim in task 8 and confirmed by a fresh `npx shadcn@latest init --base radix --preset nova` probe during task 15. Changing the oklch values here diverges from upstream shadcn, which would make future regeneration overwrite local intent and complicate theme audits. Two alternatives considered: (1) darken --muted-foreground to meet 4.5:1 and drop the 'neutral base copied from shadcn' invariant; (2) leave tokens as-is, require consumers to avoid `text-muted-foreground` on `bg-muted` for normal-size body text and prefer it only for supporting/label text (≥18pt or ≥14pt bold, which is the AA-large threshold). Option 2 matches shadcn's own usage pattern — muted-foreground is used on --background (19.79:1) far more often than on --muted.

## Decision Deferred
Did not adjust the shadcn neutral-defaults muted/muted-foreground pair despite R5 AC5 requiring 4.5:1 for normal text. In :root, --muted-foreground (oklch 0.556 0 0) over --muted (oklch 0.97 0 0) computes to 4.34:1 — AA for large text only (3:1), below the 4.5:1 normal-text threshold. .dark is fine at 5.83:1.

## Revisit Criteria
When either (a) an accessibility audit is run against the rendered site and specifically checks the muted-on-muted combination, (b) a component lands that uses `text-muted-foreground` on `bg-muted` for normal-size body text, or (c) shadcn upstream ships a palette update that nudges the default above 4.5:1.
