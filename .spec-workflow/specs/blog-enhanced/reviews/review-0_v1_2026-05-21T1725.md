## Findings

### WARNING: Criterion 4 does not exclusively test --adjust-extension
- **File:** /home/mcf/repo/matthew-field.ca/scripts/__spike/pagefind-double-build-check.mjs:350
- **Issue:** The fixture only exposes /blog/ (trailing slash, directory-index URL). wget saves trailing-slash directory responses as <dir>/index.html regardless of --adjust-extension — that flag governs extensionless leaf URLs like /about → about.html. So the assertion `htmlFiles.length > 0 && blogIndex` would pass even with --adjust-extension removed. Add a leaf extensionless URL (e.g. /about served as HTML with no trailing slash) and assert wget rewrites it to about.html to genuinely exercise the flag.
- **Task Requirement:** design.md acceptance criterion 4: --adjust-extension produces .html files from extensionless URLs

### WARNING [hygiene]: cleanup() unconditionally rm -rfs repo-root out/
- **File:** /home/mcf/repo/matthew-field.ca/scripts/__spike/pagefind-double-build-check.mjs:47
- **Issue:** `WGET_OUT = path.join(REPO_ROOT, 'out')` is the canonical Next.js static-export directory. `cleanup()` rm -rfs it on every run and at startup (`rmSync(WGET_OUT, ...)` in Steps 5/6-7), so re-running the spike on a developer machine that just ran `next export` will silently destroy that build output. Either scope wget output to a /tmp path (e.g. /tmp/pf-spike-wget) or guard with a sentinel file so the spike only deletes directories it created.

### INFO [hygiene]: Static-server child has no SIGKILL fallback
- **File:** /home/mcf/repo/matthew-field.ca/scripts/__spike/pagefind-double-build-check.mjs:211
- **Issue:** `cleanup()` only sends SIGTERM. If the child ignores SIGTERM (rare, but possible if the static-server child is mid-syscall), the script will exit but leave the child holding port 3013. A short setTimeout → SIGKILL fallback would make re-runnability bulletproof, though current behaviour is acceptable for a hand-run spike.

### INFO: Hardcoded HANG_PORT 3099 may collide on shared dev hosts
- **File:** /home/mcf/repo/matthew-field.ca/scripts/__spike/pagefind-double-build-check.mjs:442
- **Issue:** Step 11's master-timeout smoke test binds an in-process hung server to a fixed port. If 3099 is in use, hangServer.listen silently emits an `error` event (uncaught) and fetch immediately rejects, taking the .catch() path that exits 0 — which the assertion correctly flags as FAIL, so no false PASS. Still, picking an ephemeral port via `.listen(0)` and reading `.address().port` would make the spike more portable.
