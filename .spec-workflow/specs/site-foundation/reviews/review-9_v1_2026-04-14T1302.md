However, all 8 installed components import from @base-ui/react (e.g., @base-ui/react/dialog, @base-ui/react/menu) with zero @radix-ui/* packages in package.json. The steering document and downstream task requirements should be updated to reflect the actual primitive library in use, or the components should be regenerated with a Radix-based shadcn style.
