### INFO: Bounding-box assertion only covers copy button, not the three share anchors
- **File:** /home/mcf/repo/matthew-field.ca/e2e/tests/component-preview/share-bar.test.ts:42
- **Issue:** Req 6.6 requires every share button/link to meet 44×44 CSS px (and Task 40 references this assertion for coverage). The Playwright test asserts boundingBox>=44 on the copy button only; the three anchors (X, LinkedIn, mailto) share the same .share-bar-link class so they pass in practice via CSS, but the test does not prove it. A trivial loop over anchors.nth(0..2) would close the gap and match the intent of "each share button/link".
- **Task Requirement:** 6.6

### INFO: Theme-parity check depends on next-themes reacting to emulateMedia (consistent with peer slices)
- **File:** /home/mcf/repo/matthew-field.ca/e2e/tests/component-preview/share-bar.test.ts:52
- **Issue:** Tokens flip via the .dark class set by next-themes (attribute="class", defaultTheme="system"), not via @media (prefers-color-scheme). The test relies on emulateMedia({colorScheme}) causing next-themes' system listener to add/remove .dark on <html>. This is the same pattern used by series-badge / series-navigator / related-posts smoke tests, so it is an established project convention rather than a defect — but it is a hidden coupling worth noting if next-themes' system listener ever becomes unreliable across browsers. No code change required.

### INFO: Brand icons inlined instead of lucide-react (documented deviation)

Mail still comes from lucide-react. Documented in source comment (lines 11-13) and in the implementation log. Acceptable deviation — flagged only for traceability.
