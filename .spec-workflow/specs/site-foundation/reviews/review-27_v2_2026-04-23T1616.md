## Findings

### INFO: Click tests verify URL change but not destination page rendered
- **File:** e2e/tests/landing.test.ts:28
- **Issue:** After clicking a hero card, the test only asserts `toHaveURL(card.href)`. It does not verify that the destination page actually rendered (for example by asserting a heading is visible). The sibling e2e/tests/navigation.test.ts:19 pairs the URL check with `getByRole('heading', { level: 1, name: item.label })` to confirm the page loaded and wasn't, e.g., a silent 404 or a client-side-only URL change. Given that placeholder pages already use the nav label as their H1 (see navigation.test.ts), the same assertion would cheaply strengthen the hero-card flow. Arguably out of scope — the task focuses on landing-page links, not destination pages — but worth noting as a coverage gap relative to sibling conventions.
- **Task Requirement:** R6 AC3
- **Classification:** novel

### INFO: Click destinations driven entirely from siteConfig.heroCards — no cross-check against the explicit paths in the task prompt
- **File:** e2e/tests/landing.test.ts:28
- **Issue:** The test iterates `siteConfig.heroCards` and asserts `toHaveURL(card.href)`. If a future edit flipped, say, `{ title: 'Projects', href: '/projects' }` to `href: '/wrong-projects'` in siteConfig, the landing page would link to the wrong path AND the test would still pass (it reads the same wrong href and asserts against it). The task prompt explicitly lists the six expected paths (/profile, /projects, /contributions, /blog, /resources, /playground), and R6 AC2 further requires parity with the R4 AC2 mapping table (navItems). The hardcoded `toHaveCount(6)` already breaks the tautology for cardinality; consider adding an analogous hardcoded expected-path map (e.g. `expect(siteConfig.heroCards.map(c => c.href)).toEqual(['/profile', '/projects', '/contributions', '/blog', '/resources', '/playground'])`) or cross-checking heroCards hrefs against navItems hrefs so drift is caught. Classification: novel — not raised in v1.
- **Task Requirement:** R6 AC2
- **Classification:** novel
