title: Colophon
description: How this site is built and deployed.
---

This site is built with [Next.js](https://nextjs.org) using the App Router, which handles routing, server components, and static generation. Pages are styled with [Tailwind CSS v4](https://tailwindcss.com) and use [shadcn/ui](https://ui.shadcn.com) for accessible, composable UI primitives.

Content is authored in MDX and processed through [Velite](https://velite.js.org), which validates frontmatter against a typed schema and compiles MDX to React components at build time. This keeps content close to the codebase without a separate CMS.

The site is hosted on [Vercel](https://vercel.com), which handles edge delivery and preview deployments on pull requests. Continuous integration runs via [GitHub Actions](https://github.com/features/actions), enforcing type checks, linting, and content validation before anything reaches production.

The source is available on [GitHub](https://github.com/madmatt112/www.matthewfield.ca).
