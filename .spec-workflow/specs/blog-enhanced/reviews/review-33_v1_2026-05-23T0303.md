## Summary

Two-axis three-source parity implemented correctly with real extractToc and real Velite collection; gating via Pagefind probe is sound. Two non-blocking observations around source independence and Build-2 fixture-toc coverage.

## Findings

### INFO: extractToc and bodyHtml-parse share the same upstream
- **File:** e2e/tests/blog-toc.test.ts:82
- **Issue:** `extractToc()` internally calls `parse(post.bodyHtml)` and walks h2/h3, which is structurally identical to `readBodyHtmlHeadingIds`. Asserting `extractTocIds === bodyHtmlIds` therefore mostly proves extractToc didn't filter/reorder anything, not that two independent pipelines agree. The rendered-DOM source is the only truly independent leg. Not a defect — rendered vs bodyHtml is the load-bearing assertion for the `s.mdx()` vs `s.markdown()` parity claim in Req 7.4 — but worth noting the three-source framing is closer to two-and-a-half-source.
- **Task Requirement:** 7.4

### INFO [hygiene]: extractToc <2 heading guard could mask divergence
- **File:** e2e/tests/blog-toc.test.ts:62
- **Issue:** `extractToc` returns `[]` when fewer than 2 headings exist. If a future fixture trips this branch, `expect(extractTocIds).toEqual(bodyHtmlIds)` would silently pass only when bodyHtml also has <2 headings, and fail noisily otherwise. Current fixtures clear the threshold so this is latent. Comment at line 77-80 acknowledges this. Consider a guard like `expect(extractTocIds.length).toBeGreaterThanOrEqual(2)` to make the assumption explicit.

### INFO: Build 2 fixture-toc check skips rendered DOM
- **File:** e2e/tests/blog-toc.test.ts:140
- **Issue:** The Build 2 fixture-toc duplicate-heading test asserts only extractToc vs bodyHtml parity (source-level), not rendered DOM, because the draft isn't routable in Build 2. The inline comment justifies this. It still leaves Build 2 with only one full three-source assertion (fixture-search). Acceptable but the duplicate-heading rendered-DOM coverage lives exclusively in Build 1 via fixture-code.
- **Task Requirement:** 7.3
