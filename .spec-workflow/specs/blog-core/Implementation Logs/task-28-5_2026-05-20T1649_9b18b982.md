#### extractRequirementIds
- **Purpose:** Walks requirements.md collecting AC IDs (N, N.M, N.Ma) scoped to each '### Requirement N:' section. Pinned regexes: REQ_HEADER_RE (/^###\s+Requirement\s+(\d+)\s*:/), AC_LINE_RE (/^(\d+)\.\s/), SUB_ID_RE (/\b(\d+)\.(\d+)([a-z])\b/g).
- **Location:** scripts/verify-requirements-coverage.mjs
- **Exported:** No

#### parseMatrix
- **Purpose:** Parses the `## Requirements Coverage Matrix` section in tasks.md, extracting cited requirement IDs (bullet LHS) and cited task numbers (bullet RHS, parenthetical notes stripped). Returns sets used by orphan/dangling/unknown-task checks.
- **Location:** scripts/verify-requirements-coverage.mjs
- **Exported:** No

#### extractTaskNumbers
- **Purpose:** Walks tasks.md skipping the matrix region, harvests top-level and sub-task headers ('- [ ] N.' and '  - **N.M ...**') into a Set used to validate matrix RHS task refs.
- **Location:** scripts/verify-requirements-coverage.mjs
- **Exported:** No

#### parseTasks / parseDepsBody
- **Purpose:** Two-pass parser. Pass 1: collect every task header with its starting line. Pass 2: scan each task's footer block (up to the next header) for a single `_Depends on:_ ...` line; parseDepsBody strips parenthetical notes (e.g. '28 (matrix wait, 28 depends on this; ...)') and recognises 'none' as zero edges.
- **Location:** scripts/verify-task-dependencies.mjs
- **Exported:** No

#### topoSort
