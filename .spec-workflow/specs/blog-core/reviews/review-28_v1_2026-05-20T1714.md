### WARNING: verify-production-build.mjs emit-shape patterns stale against Next.js 16 (Task 18)
- **File:** scripts/verify-production-build.mjs
- **Issue:** Next.js 16 emits rendered pages as flat files (.next/server/app/blog.html, .next/server/app/sitemap.xml.body) rather than directory-shaped (.next/server/app/blog/page.html). The verify-production-build.mjs EMIT_SHAPES patterns from Task 18 expect the directory shape; the script now fails 'emit-shape gate FAILED' for index-page/sitemap/feed even though the rendered output IS present and correctly draft-free. The script also greps .next/server/chunks/** which hits fixture-code in source-map bundles where the full posts.json (including drafts) is embedded as SSG data — false-positive draft 'leaks'. Semantic Build 2 isolation IS correct: .next/server/app/ rendered output contains zero fixture mentions. Resolution: tighten SCAN_ROOTS to '.next/server/app/**' (drop chunks/) and update EMIT_SHAPES to Next.js 16 flat-file shapes ('**/server/app/blog.html', '**/server/app/sitemap.xml.body', '**/server/app/feed.xml.body'). Surfaced by Task 28 exactly as the script was designed (emit-shape drift fails loudly rather than silently passing).
- **Task Requirement:** Both verify scripts MUST exit 0

### WARNING: validate-feed.mjs FEED_GLOB stale against Next.js 16 (Task 19)
- **File:** scripts/validate-feed.mjs
- **Issue:** validate-feed.mjs uses FEED_GLOB = '**/server/app/feed.xml/**/*' which requires feed.xml to be a directory; Next.js 16 emits feed.xml.body as a sibling file (with feed.xml/ as a sibling directory containing only route bundles, not the rendered XML body). Resolution: extend FEED_GLOB to also match '**/server/app/feed.xml.body'.
- **Task Requirement:** node scripts/validate-feed.mjs should exit 0

### WARNING: Axe color-contrast failure on /blog/fixture-code light theme (newly visible after Shiki cascade fix)
- **File:** src/styles/globals.css
- **Issue:** After the globals.css patch made the Shiki cascade actually resolve to per-token colors, axe surfaced a pre-existing WCAG AA contrast gap: (1) DraftBanner destructive surface #e7000b/#fde6e7 = 4.0:1 (needs 4.5:1 normal text); (2) Shiki github-light orange identifier token #e36209 on white #ffffff = 3.48:1. Resolution: darken the orange token via a CSS override (e.g. --shiki-light: #a04a04) and tighten DraftBanner foreground color. Recommend logging as a follow-up task for blog-enhanced.
