#### Integration
- **Description:** Two-part CSS isolation boundary for the playground route group. (1) Unlayered .playground-container rule applies all: initial, isolation: isolate, display: block, box-sizing: border-box, unicode-bidi: normal — wiping inherited site styles at the container boundary. (2) @layer playground (declared at lowest priority in src/styles/globals.css from task 8) re-establishes font-family, font-size, line-height, color, box-sizing, color-scheme: light, -webkit-text-size-adjust, and the full shadcn/ui token set (light-mode values mirrored from src/styles/tokens.css :root) on .playground-container so descendants resolve playground-scoped tokens regardless of the host site theme. Light-mode only by design — task 13 verifies the playground stays light when the site is in dark mode. Whether this layered re-establishment effectively coexists with the unlayered all: initial reset is the empirical question the spike will answer in tasks 11-13.
