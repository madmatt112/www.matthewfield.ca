## Findings

### INFO: Justified deviation: outer wrapper is <div> not <main>
- **File:** src/app/(site)/profile/page.tsx:23
- **Issue:** Design §Component: /profile/page.tsx specifies `<main className="mx-auto max-w-5xl px-...">`, but `(site)/layout.tsx` → `SiteShell` already renders `<main className="flex-1">` around `{children}`. Using `<main>` again here would nest landmarks, which violates ARIA Landmark practice (one `<main>` per page) and would still allow Playwright's `page.locator('main')` to find a hit. The implementer chose `<div>` with the design's container classes preserved (`mx-auto w-full max-w-5xl px-4 py-12 sm:py-16`). This is the correct a11y resolution of an overspecified design literal. No change required.

### INFO [hygiene]: pnpm build not run locally — deferred to same-commit landing
- **File:** src/app/(site)/profile/page.tsx
- **Issue:** Per Req 1.14, content/profile.mdx and the consuming page must land in the same commit; Velite's profile transform throws on the empty `git log` output if profile.mdx is uncommitted, so `pnpm build` cannot be exercised standalone. `pnpm typecheck` and `pnpm lint` both pass against the current working tree. Build success is properly deferred to task 24's preview-deploy verification after the same-commit landing.
