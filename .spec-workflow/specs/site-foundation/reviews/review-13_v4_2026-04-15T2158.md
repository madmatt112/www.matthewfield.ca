## Findings

### WARNING: Font-family assertion matches sans-serif (false-positive risk)
- **File:** e2e/tests/playground-isolation.test.ts:70
- **Issue:** Line 70 uses `expect(styles.fontFamily.toLowerCase()).toContain("serif")` which would also match "sans-serif" or "ui-sans-serif". If global styles leaked and the computed font-family resolved to the playground's sans-serif stack (e.g. "ui-sans-serif, system-ui, ..."), the assertion would still pass. This defeats the purpose of the test — proving globals don't leak. Use `toBe("serif")` or a regex like `/^serif$/i` to avoid matching sans-serif variants.
- **Task Requirement:** R11 AC2

### WARNING: R11 AC3 partially unmet — Button background/color not asserted
- **File:** e2e/tests/playground-isolation.test.ts:76

- **Task Requirement:** R11 AC3
