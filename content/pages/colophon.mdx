title: Colophon
description: How this site is built and deployed.
---

This site is built with <a href="https://nextjs.org" rel="noopener">Next.js</a> using the App Router, which handles routing, server components, and static generation. Pages are styled with <a href="https://tailwindcss.com" rel="noopener">Tailwind CSS v4</a> and use <a href="https://ui.shadcn.com" rel="noopener">shadcn/ui</a> for accessible, composable UI primitives.

Content is authored in MDX and processed through <a href="https://velite.js.org" rel="noopener">Velite</a>, which validates frontmatter against a typed schema and compiles MDX to React components at build time. This keeps content close to the codebase without a separate CMS.

The site is hosted on <a href="https://vercel.com" rel="noopener">Vercel</a>, which handles edge delivery and preview deployments on pull requests. Continuous integration runs via <a href="https://github.com/features/actions" rel="noopener">GitHub Actions</a>, enforcing type checks, linting, and content validation before anything reaches production.

The source is available on <a href="https://github.com/madmatt112/www.matthewfield.ca" rel="noopener">GitHub</a>.
