## Findings

### WARNING: Overly broad .prettierignore patterns match at any depth
- **File:** .prettierignore:9
- **Issue:** The bare patterns `research` and `project-overview.md` in .prettierignore follow .gitignore rules: a pattern without a `/` matches at any directory depth. This means any future file named `research` (e.g., `src/utils/research.ts`) or `project-overview.md` anywhere in the tree will be silently excluded from Prettier formatting. Use leading-slash patterns (`/research`, `/project-overview.md`) to restrict matching to the project root, which is the apparent intent.
