## Context
During Task 9, the Playwright E2E harness (scripts/run-e2e.mjs, which rebuilds under NODE_ENV=test) failed because Tailwind v4 auto content-detection scans committed .spec-workflow review markdown, finds a literal bg-[var(...)] arbitrary class, and Turbopack chokes parsing the generated CSS. Normal `pnpm build` passes; only the test build fails. Confirmed pre-existing and independent of the Task 9 changes (reproduces with edits stashed). This blocks `pnpm test:e2e` for this spec's own verification tasks (16,21,22,23) and any future spec needing E2E.

## Decision Deferred
Whether/how to exclude .spec-workflow/**/*.md (and other non-source docs) from Tailwind v4 content scanning so example utility classes (e.g. literal bg-[var(...)] in review prompts) do not generate CSS and break the build.
