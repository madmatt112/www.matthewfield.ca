### WARNING: Test 1 description mismatches what is actually asserted
- **File:** e2e/tests/playground-isolation.test.ts:63
- **Issue:** The describe block / outcome (line 19 of summary, line 63 of test) claims to verify "site globals do NOT leak past the .playground-container reset". The test asserts that an inline style="color:red; font-family:serif" on a child div produces rgb(255, 0, 0) and "serif" — but inline styles win over inherited styles regardless of any isolation strategy, so this assertion proves only that inline styles work, not that site globals are isolated. To actually prove R11 AC2 ("the site's global styles SHALL NOT affect it"), the test would need a child element WITHOUT inline overrides whose computed color/font-family matches the @layer playground re-established defaults rather than any host-site value, or a fixture where a known-conflicting global rule is intentionally placed in the host scope. As written, Test 1 would still pass even if the .playground-container reset were removed entirely.
- **Task Requirement:** R11 AC2
