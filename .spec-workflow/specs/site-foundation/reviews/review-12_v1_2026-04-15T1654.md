## Findings

### WARNING: Containment matrix understates available mitigation paths
- **File:** src/app/(playground)/spike/spike-overlays.tsx:18
- **Issue:** The matrix (lines 3-20) states that containment requires 'composing with the underlying Radix primitive directly' (line 18-19). However, shadcn/ui already exports standalone Portal wrappers that forward all props via spread: DialogPortal (dialog.tsx:22-26) and DropdownMenuPortal (dropdown-menu.tsx:15-19) both accept and forward the `container` prop. For Dialog and DropdownMenu, a user could compose <DialogPortal container={ref}><DialogOverlay /><DialogPrimitive.Content>... without dropping down to raw Radix imports. Only Popover, Tooltip, and Select lack an exported Portal wrapper. The matrix should distinguish these two mitigation tiers: (1) use the already-exported shadcn Portal wrapper with container prop, vs. (2) drop to raw Radix primitives.
- **Task Requirement:** R11 AC6 — document mitigation path

### INFO: Misleading comment on contained dialog portal target
- **File:** src/app/(playground)/spike/spike-overlays.tsx:100
- **Issue:** Line 100 states 'Portal targets .playground-container via container prop' but the portal actually targets the portalHost div (line 91), which is a descendant of .playground-container. The portal does NOT target .playground-container itself. The distinction matters for task 13's Playwright assertions: closest('.playground-container') on the portal content will return the layout wrapper (not the portal host), which is correct but for a different reason than the comment implies.
- **Task Requirement:** R11 AC6
