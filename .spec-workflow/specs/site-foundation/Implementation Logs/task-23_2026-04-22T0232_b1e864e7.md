- **Frontend Component:** src/app/(site)/about/page.tsx + src/components/shared/mdx-content.tsx
- **Backend Endpoint:** n/a (build-time import from #site/content)
- **Data Flow:** velite build → .velite/pages.json → #site/content default export → AboutPage finds entry by slug → MDXContent({ code: entry.body }) → new Function(code)(jsxRuntime).default component → rendered HTML
